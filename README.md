# GZIST-Hotspot —— 校园网有线转热点工具（v2.0.0 · Go 版）

> 一台插网线的电脑（**台式机 / 笔记本均可**）走有线网上校园网（一账号一设备），**点一下按钮**就把有线网变成 WiFi 热点，给手机 / 笔记本 / 平板共享上网。
> **广州理工学院校园网实测可用**（2026-10 真机验证），其他「一账号一设备」的校园网环境同样适用。
>
> v2.0.0 起为 **Go + mygo 框架重写的图形界面版**：单文件 exe、托盘常驻、可视开关，无需再碰命令行。

## 适合谁用

**✅ 适合你，如果：**

- 你的校园网（或公司/宿舍网）是**「一账号一设备」**——新设备登录会把已在线的设备踢下线，两台设备互相踢
- 你有一台**带有线网口且能上网**的电脑（台式机插网线最典型；笔记本插网线同样行，轻薄本没网口加个转接头即可）
- 你想给手机 / 平板 / 其他笔记本共享网络，但**不想买第二个路由器、不想一直开手机热点、不想折腾命令行**
- 你的电脑是 Windows 10（1809+）或 Windows 11
- 你希望共享这件事**常驻托盘、点一下就完成**，状态、日志一眼可见

**❌ 帮不了你，如果：**

- 电脑的无线网卡**不支持 Wi-Fi Direct** 且你不想换卡（下方有 10 秒自查命令和选购指南，先查再下结论——很多近几年的内置网卡其实支持）
- 电脑**没有可用的有线网络**（本工具的唯一上行就是网线；纯 WiFi 环境请用系统自带「移动热点」直接连 WiFi 源）
- 你在用 macOS / Linux（本工具是 Windows 专属）
- 你的学校明令禁止网络共享且你不想承担风险（技术上一台主机共享完全可行，但请先了解并遵守学校规定）

## 为什么需要它

很多校园网是「一账号一设备」：新设备登录会把已在线的设备踢下线，两台设备就会互相踢成乒乓球。

本方案 = **只让一台电脑（下称「主机」）登录校园网，其他设备全部连主机的热点**。热点客户端的流量经 Windows ICS 做 NAT 转发，从主机的有线网出去——校园网自始至终只看到一台已认证设备，客户端隔离 / ACL 策略完全管不到热点内部（热点是两台机器之间的直连，根本不经过校园网）。

## 功能特性

- **图形界面 + 托盘常驻**：开热点 / 关热点 / 刷新是三个按钮；关掉窗口仍在托盘待命，图标随状态变化（绿色星 = 本程序，与校园网保活的蓝色星区分）
- **一键开关，全程无感**：无需管理员权限、不弹 UAC、无控制台窗口，进度和结果实时显示在界面日志区（「灯的笔记本」）
- **防断网设计**：自动处理 Clash TUN 冲突（TUN 与热点互斥、双向实测都会整机断网；程序先经 mihomo 管道 API 关 TUN，验证直连可用后才继续）
- **失败自动回滚**：任何一步失败，自动清理半开热点状态、自动还原 TUN，保证网络始终活着
- **三重信号交叉验证**：tethering 状态 / WFD 虚拟适配器 / SSID 实际广播，三项互证后才报「开启成功」
- **凭据安全**：热点密码存 **Windows 凭据管理器**（不可用时回退 0600 权限文件），不进命令行、不明文落盘
- **开机自启开关**：界面里一键设置，登录后托盘待命（不会自动开热点）
- **网卡自适应**：优先找指定 USB 网卡，找不到自动回退任意物理无线网卡，换网卡不用改配置
- **旧配置自动迁移**：PowerShell 版的 `hotspot_config.json` 放在程序旁边，首次启动自动导入
- **单文件绿色程序**：12.7 MB 一个 exe，WinRT 调用内嵌解决，解压即用、删除即卸

## 使用前提（开热点前必读）

能不能用起来，取决于两类条件：**网卡决定热点能不能开起来，网络环境决定连上后能不能出网**。先对照检查，再动手。

### 一、网卡条件 —— 决定热点能不能开起来

Windows 移动热点走的是 **Wi-Fi Direct（WFD）**，不是老式软AP，对无线网卡有硬性要求。

**自查命令**（10 秒出结果，下单买卡前先跑这条）：

```powershell
netsh wlan show wirelesscapabilities
```

在你的无线网卡段落里找这三行，**必须全是「支持」**：

```
Wi-Fi Direct 设备   : 支持
Wi-Fi Direct GO     : 支持
Wi-Fi Direct 客户端 : 支持
```

**实测对照**：

| 网卡 | 结果 | 说明 |
|---|---|---|
| MediaTek MT7922（Wi-Fi 6E，内置） | ✅ 完美 | 本项目主力实测卡：热点吞吐 257 Mbps+，可带 8 客户端 |
| Realtek RTL8811CU（USB，WiFi 5，绿联 CM496 等） | ❌ 不可用 | 只支持老式软AP，WFD 三项全「不支持」——**我们真实买错的卡** |
| Intel AX200 / AX210 等（Wi-Fi 6/6E，内置） | ✅ 通常支持 | 理论兼容，仍以自查命令的实际输出为准 |

**经验规律**：

- 2019 年之后的**内置**网卡（Intel AX 系列、MT7922/MT7925 等）基本都支持 WFD——**先查机器自带的网卡，大概率不用花钱买卡**
- 廉价 **USB 迷你网卡是重灾区**：很多只支持老式软AP。商家说「支持开热点」往往指软AP，与本工具无关；拿不准就收货后先跑自查命令再决定退不退
- 网卡不支持 WFD = 热点永远开不起来，而且往往是**静默失败**——这是硬件能力缺失，任何工具都绕不过去
- 网卡支持但热点还是开不了？十有八九是「Microsoft Wi-Fi Direct Virtual Adapter」幻影化，修复配方见下方「排障」

### 要买的话，按这个优先级买

| 方案 | 推荐型号 | 参考价 | 说明 |
|---|---|---|---|
| **台式机首选** | **Intel AX210 PCIe 套装**（自带 2 根外置天线） | ¥60~90 | Intel 卡对 WFD 的支持没有悬念；Wi-Fi 6E；天线伸出金属机箱，信号好 |
| 台式机预算款 | Intel AX200 PCIe 套装（带天线） | ¥40~60 | Wi-Fi 6，同样稳，够用 |
| 笔记本换内置卡 | Intel AX210 M.2 版（2230 规格） | ¥50~70 | 仅适合愿意拆机、且机器无网卡 BIOS 白名单的情况；动手前先查自己机器型号的拆机难度 |
| USB 网卡 | **没有可靠型号可推荐** | — | USB 卡驱动五花八门，Realtek 系大概率不支持 WFD；真要买，务必选支持 7 天无理由退货的店，**收货第一件事跑上面的自查命令** |

**避雷清单**：Realtek 系 USB 迷你棒——**RTL8811CU / RTL8821CU / RTL8822BU** 等（常见于绿联、COMFAST 等品牌的入门款），多数只支持老式软AP，对这个用途**完全无用**（本项目作者就是买了绿联 8811CU 后发现开不了热点才转向内置卡的真实案例）。

**买前三问**（问客服或看商品页）：

1. 芯片是不是 Intel（AX200/AX210）？——是，基本可以下单
2. 台式机 PCIe 套装**是否带外置天线**？——不带天线插进金属机箱里信号会很差
3. 不支持能否 7 天无理由退货？——保底手段，收货先跑自查命令再确认收货

**天线提醒**：台式机无论 PCIe 还是 M.2 转接卡，都**必须带外置天线**并让天线伸出机箱；裸卡藏在金属机箱里，信号衰减立竿见影。

### 二、网络环境条件 —— 决定连上后能不能出网

1. **主机必须有一段能上网的有线连接**（本项目的唯一上行）：以太网插网线且能上网。校园网环境 = 主机先完成认证登录（可配合 [GZIST-NetKeeper](https://github.com/xiaomai1011/GZIST-NetKeeper) 自动认证 + 掉线保活，开机 20~30 秒自动完成认证）
   - **笔记本当主机完全可行**，而且往往更方便：自带无线网卡近年基本都满足上面的 WFD 条件，插根网线就行。唯一注意点：没有 RJ45 网口的轻薄本需要一个 USB / Type-C 转网口的转接头
2. **「一账号一设备」的校园网正是本项目的目标场景**：热点客户端的流量经 Windows ICS 做 NAT，从主机的有线网统一出去——校园网自始至终只看到主机一台已认证设备。热点本身是主机与客户端之间的直连，不经过校园网的认证设备
3. **客户端零配置**：手机 / 平板 / 笔记本连上热点即可访问国内资源，无需装任何东西；需要国际网络时由客户端自行配置代理
4. **主机在用 Clash 等代理软件的注意**：TUN 模式与热点**互斥**（双向实测都会整机断网）。热点期间请用「系统代理」模式——程序会自动关闭 TUN 并在结束后保持 TUN 关闭（界面上有标注），属正常现象；开热点前建议先在 Clash 界面手动关掉 TUN 开关（让界面记住「关」，避免 Clash 重载时把 TUN 写回来）
5. **不需要准备的东西**：第二台路由器 ✗、管理员权限 ✗、公网 IP ✗、额外服务器 ✗——Windows 自带的移动热点 + ICS 全部搞定
6. ⚠️ **政策提醒**：NAT 共享意味着校园网只看到一台设备，但部分学校的网络使用规定可能限制此类共享行为，请先了解并遵守学校规定，自行评估风险

## 快速开始

1. 从 [Releases 最新版](https://github.com/xiaomai1011/GZIST-Hotspot/releases/latest) 下载 `GZIST-Hotspot-v2.0.0.exe`（绿色单文件，或下载 Setup 安装器）
2. 双击运行 → 首次启动自动弹出主窗口，在「热点设置」里填**热点名称和密码**（至少 8 位）→ 点「保存」（密码存入 Windows 凭据管理器）
3. 确认主机有线网能上网，点 **「开热点」**，等 1~2 分钟，界面显示「热点开启中」即成功
4. 手机 / 笔记本搜到热点名，连上即可上网；关闭点「关热点」，或直接关窗口留在托盘

**命令行模式**（可选）：`GZIST Hotspot.exe -selftest` 做只读自检（打印配置、TUN 状态、热点发现结果，绝不动热点），排查环境时有用。

### 从 PowerShell 版升级（v1.x → v2.0.0）

- 把旧的 `hotspot_config.json` 放到新 exe 旁边，**首次启动自动导入**热点名和密码，导入后可删除
- 旧版的 bat 脚本、说明文档完整保留在 [`powershell-legacy` 分支](https://github.com/xiaomai1011/GZIST-Hotspot/tree/powershell-legacy)，需要命令行模式可去那里下载
- 两版可共存，互不干扰

## 工作原理

1. 经 mihomo/Clash 的**命名管道 API** 关闭 TUN（避免 TUN 抢默认路由导致断网）
2. 调 Windows `NetworkOperatorTetheringManager`（WinRT）配置并启动移动热点（WFD GO）——Go 主程序内嵌 PowerShell 5.1 引擎完成 WinRT 调用，单文件搞定，无需安装任何运行时
3. Windows ICS 自动把热点客户端流量 NAT 到有线网出口
4. 三重信号交叉验证（tethering 状态 / WFD 虚拟适配器 Up / 自扫到 SSID 广播），判定真实结果
5. 失败则停止热点清理状态，并把 TUN 恢复原样

## 排障

热点反复开不起来的头号元凶：Windows 的「Microsoft Wi-Fi Direct Virtual Adapter」设备节点**幻影化**（重启 / 网络重置 / DISM+SFC 都修不好），症状是热点怎么开都失败、事件日志零记录。

完整修复配方（`pnputil` 删幻影节点 + 重初始化物理网卡，实战验证 5 分钟可修好）见 [`powershell-legacy` 分支的排障手册](https://github.com/xiaomai1011/GZIST-Hotspot/blob/powershell-legacy/重启后操作清单.md)。
